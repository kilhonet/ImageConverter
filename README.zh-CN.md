## 概述

iPhone 拍的 HEIC 照片在电脑上打不开,要把博客用的照片一次性缩小,需要把 PDF 按页导出成图片 —— ImageConverter 都能搞定。

把文件或文件夹拖进窗口,点击 **转换为** 按钮即可。JPG 用 MozJPEG 保存得更小;指定尺寸后,会保持比例缩小或放大。也可以在资源管理器中右键点击文件直接转换。

转换结果总是保存为 **新文件**。绝不会覆盖原始文件或已有的文件。

## 主要功能

- **一次转换多张** — 多个文件、整个文件夹(含子文件夹)放进列表一起转换。
- **5 种保存格式** — JPG · PNG · GIF · WEBP · TIFF。
- **支持多种输入格式** — JPG、PNG、GIF、BMP、WEBP、TIFF、HEIC、AVIF、PSD、PDF、SVG、TGA、ICO 等。
- **更小的 JPG** — 用 MozJPEG 以更小的体积保存同样的画质。
- **保持比例调整尺寸** — 只需设定宽度或高度,另一边按比例自动确定。
- **PDF → 图片** — 把多页 PDF 按页各保存为一张图片。
- **没有扩展名也能识别** — 根据文件内容而不是文件名判断格式。
- **保护原文件** — 有同名文件时,以 `photo (1).jpg` 这样的新名称保存。
- **资源管理器右键菜单** — 支持 Windows 10 · 11,也会出现在 Windows 11 的默认菜单中。
- **7 种语言** — 韩语 · 英语 · 日语 · 中文 · 俄语 · 意大利语 · 法语。跟随 Windows 显示语言。

## 使用方法

### 快速上手

1. 运行 ImageConverter。**主页** 上显示空的文件列表。
2. 把要转换的图片文件或文件夹拖到列表中。只有能识别格式的文件才会加入,**类型** 列显示原始格式,**状态** 列显示 `准备`。
3. 在左下角的尺寸框中选择 **原始** · **宽度** · **高度** 之一。选择宽度或高度时,旁边会出现尺寸(px)框。
4. 确认保存格式。右下角按钮上写着当前格式,例如 **转换为 JPG**。要更改时,**右键点击** 按钮,从 JPG · PNG · GIF · WEBP · TIFF 中选择。
5. 点击按钮。出现进度条,每个文件的状态依次变为 `转换` → `成功`。
6. 转换后的文件默认保存在 **与原文件相同的文件夹** 中,文件名不变,扩展名为新格式。

### 这种情况怎么办

**想把 iPhone 照片(HEIC)转换为 JPG**
把 HEIC 文件或装有照片的文件夹拖到列表中,格式保持 **JPG**,点击按钮。照片会按手机记录的旋转信息以 **正确的方向** 保存,横躺的照片不必再手动旋转。

**为博客或网店统一照片尺寸**
在尺寸框中选择 **宽度**,选好想要的宽度,例如 `1280`。高度按比例自动确定,照片不会变形。列表中没有的数值,直接在框中输入数字即可(1 ~ 30000)。比指定宽度小的照片也会调整到该宽度。

**像缩略图那样统一高度**
选择 **高度** 后,所有结果的高度相同,宽度各按自身比例确定。横图和竖图混在一起时,也便于排成一行。

**缩小体积以便通过邮件或聊天软件发送**
格式设为 **JPG** 时,会用 MozJPEG 以更小的体积保存同样的画质。想再缩小,可把 **设置 → 质量调整** 降到 60 左右,同时用 **宽度** 缩小尺寸,效果更明显。保存为 **WEBP** 通常比 JPG 更小。

**想保留透明背景**
带透明背景的 PNG · SVG 等保存为 **PNG** 或 **WEBP** 时,透明部分原样保留。JPG 无法保存透明,Logo 和图标请选择 PNG · WEBP。

**把 SVG Logo 导出为所需尺寸的 PNG**
放入 SVG,把 **宽度** 设为 `512` 等值,转换为 **PNG**。不是把小图放大,而是 **按指定尺寸重新绘制**,所以导出得再大也清晰。

**把 PDF 按页转换为图片**
放入 PDF 后转换,每一页会保存为 `document-001.jpg`、`document-002.jpg` … 这样带编号的文件。选择 **原始** 时按屏幕显示大小输出;指定 **宽度** 时会按该宽度清晰绘制。背景为白色。所有页面都保存后,状态显示 `成功`。

**把动图 GIF 转换为 WEBP**
保存格式为 **GIF** 或 **WEBP** 时,动画的所有帧都会原样保留。把动图 GIF 转为 WEBP,动画不变,体积变小。保存为 JPG · PNG · TIFF 时,只保存第一帧。

**想无损保存为 WEBP**
把 **质量调整** 调到 **100**,WEBP 就以无损方式保存。想在像素完全一致的前提下保存得比 PNG 更小时使用。

**一次转换文件夹里的所有图片**
把整个文件夹拖进来,会扫描所有子文件夹,只把图片文件加入列表。文档、视频等其他文件会自动排除,同一个文件也不会重复加入。

**文件没有扩展名或扩展名不对**
ImageConverter 根据 **文件内容** 而不是文件名判断格式。没有扩展名的文件,或者名为 `.jpg` 实际是 PNG 的文件,都能正确识别,结果会带上正确的扩展名。

**想把转换结果集中到一个文件夹**
在 **设置 → 输出路径** 中选择下方的文件夹选项,所有结果都会存到该文件夹。默认是 `桌面\ImageConverter`,文件夹不存在时会在转换时自动创建。可用 `…` 按钮选择其他文件夹。想放在原文件旁边,选择 **原始文件夹**。

**已有同名文件时**
不会覆盖任何文件。已有 `photo.jpg` 时,会以 `photo (1).jpg`、`photo (2).jpg` … 这样的新名称保存。即使把 JPG 再压缩成 JPG,原文件也会原样保留。

**想在资源管理器中直接转换**
在资源管理器中选中一个或多个图片文件,右键 → **图片转换** → **转换为 WebP** · **转换为 PNG** · **转换为 JPG** 中的一项。会打开装有这些文件的窗口,选好尺寸后点击按钮。
- 结果保存在 **与原文件相同的文件夹** 中,转换完成后窗口会自动关闭。
- 再右键其他文件进行转换时,会各自打开窗口,可以同时进行。
- 选中 JPG · PNG · GIF · BMP · WEBP · TIFF · HEIC · AVIF · PSD · PDF · SVG · TGA 文件时显示该菜单。

**把同一批照片做成多种格式**
转换结束后列表仍然保留。右键点击按钮更换格式后再点一次,就能把同样的文件再转换成另一种格式。

**整理列表**
选中要移除的行(用 `Ctrl` · `Shift` 选多行),右键点击列表选择 **删除**。要全部清空,选择 **全部删除**。只是从列表中移除,实际文件不会被删除。

**想在转换途中停止**
关闭窗口时会询问 **停止转换并退出？**。点击 **是**,会处理完当前正在转换的文件后退出。已经保存的结果会原样保留。
